Justificación de prioridades (Alta)

1. Refactorizar código
El código tiene muchos errores de escritura y problemas de diseño. Si no lo arreglamos ahora, después será más difícil. Además, la profesora revisa el código y es mejor tenerlo limpio.

2. Validar entradas
El programa se rompe si el usuario ingresa mal los datos. Por ejemplo, si ponen un nombre vacío o letras donde va un número. Esto debe arreglarse primero.

3. Reportes mejorados
La aerolínea necesita ver los reportes de ventas. Sin esta funcionalidad, el sistema no sirve para el negocio. Es lo que pide el cliente.

Decidimos estas 3 prioridades porque son las que más valor aportan al usuario final y son base para las demás funcionalidades.
